## Data Vault

Требуются PostgreSQL 16+ и расширение pgcrypto. Бизнес-ключи сравниваются с учётом регистра, без изменения значений источника. На одну партию приходится один согласованный снимок данных; партии подаются по возрастанию времени загрузки. Код задания уникален во всей учебной системе. В исходном примере одна связь фиксирует сдачу одной работы студентом по дисциплине; повторные попытки отдельно не моделируются.

```sh
psql -v ON_ERROR_STOP=1 -f 01_Data_Vault/01_schema.sql
psql -v ON_ERROR_STOP=1 -f 01_Data_Vault/02_data_and_checks.sql
```

Пример в отдельной учебной Docker-базе:

```sh
docker run -d --name dw-lab-pg -e POSTGRES_PASSWORD=lab_only_password postgres:16
docker exec -i dw-lab-pg psql -U postgres -v ON_ERROR_STOP=1 < 01_Data_Vault/01_schema.sql
docker exec -i dw-lab-pg psql -U postgres -v ON_ERROR_STOP=1 < 01_Data_Vault/02_data_and_checks.sql
```

Запускайте команды после готовности сервера. Проверочный сценарий очищает только staging-таблицу учебной схемы `lab_dv`. Итог: 3 студента, 1 дисциплина, 2 задания, 4 связи, 6 версий сателлита сдач, 1 отклонённая запись. Возврат к прежнему состоянию создаёт новую историческую версию.

## Neo4j

Требуется Neo4j 5.26. Скрипт `01_social_graph.cypher` создаёт 14 узлов и 36 рёбер. Повторный запуск не удваивает граф. `02_queries_and_checks.cypher` содержит практические запросы, поиск соседей, коротких путей и проверки удаления на отдельных тестовых узлах.

```sh
cypher-shell -f 04_Neo4j/01_social_graph.cypher
cypher-shell -f 04_Neo4j/02_queries_and_checks.cypher
```

При настроенной аутентификации укажите свои параметры подключения. Основной учебный граф отмечен меткой `LabEntity`; демонстрационное удаление затрагивает только `LabDeleteDemo` и `LabTemp`. Внутренний `id()` показан для соответствия старой лекции; прикладной ключ `id` применяется для устойчивого поиска.

## Проверки

Сценарии выполнены на реальных PostgreSQL и Neo4j, затем повторно запущены. Дополнительно SHA256 проверен независимым расчётом, а длины кратчайших путей — независимым обходом BFS. Результаты сохранены в `check_results.txt` и `verification_summary.txt`.
